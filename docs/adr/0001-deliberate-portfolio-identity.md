# Develop one identity while preserving the design experiments

The owner chose one deliberate portfolio identity on 2026-10-17 (interview Q4), replacing the all-ten-palettes constraint for future design work while retaining the existing previews. This allows colour, imagery, typography, and content to be composed together instead of requiring every future composition to work across a palette matrix. Existing routes and designs remain intact; future apps should share a family resemblance with room for distinct project character (Q6), as recorded in the [brief](../design/brief.md).
